# Changelog

## 0.1.0

First release.

- One searchable list of Flatpak, Snap, Homebrew, rpm-ostree, Distrobox, Toolbox, AppImage, Steam, local and system apps.
- Works on Fedora (including Bazzite, Silverblue, Kinoite), Ubuntu, Debian, Arch and openSUSE; system packages are removed with the distro's own package manager.
- Confirmation dialog that shows the exact commands; recoverable removals go to the trash; opt-in cleanup of leftover config and data.
- Update badges with one-click update, update all, and daily automatic updates through a systemd user timer.
- Update banner for new App Manager releases.
- Protected core packages, System labels, and select-all that never picks system apps.
- `--list`, `--demo`, `--update-all`, `--version`, `--shot` command line options.
